Greed

A modal text editor with Helix, Vim and VS Code keys, a shell, terminals and agent support. The core is a small Rust program; the rest is written in Luau plugins that you can read and change. It runs in a terminal or in its own window, locally or over ssh.

Install Docs

Helix, Vim or VS Code keys

Pick a style on first start; :style switches later. Each style has its own modes. Commands, pickers and plugins are shared.

Editing styles

Helix

% s todo enter c done

Select every todo, change them all.

Vim

:%s/todo/done/g

Substitute, with a preview as you type.

VS Code

ctrl-d ctrl-d done

Add the next match as a cursor.

Sessions and ssh

The editor runs as a session. :detach leaves it running with its files, undo history, shells and language servers; greed attach comes back to it. greed ssh HOST runs the session on the remote machine and shows it here, with your local keys, theme and config.

Editing on another machine

$ greed src/main.rs
$ greed --gui         # same session, in a window
:detach
$ greed attach
$ greed ssh build-box

Shell

:shell keeps each command's output as a block you can search, filter and run again. Tables from kubectl, docker or ps can be filtered (where STATUS != Running) and charted. A terminal pane runs your own shell when you need one.

The shell

Live Markdown

Fields, formulas and computed table columns, updated as you edit, with charts under tables. Data blocks read CSV, SQLite or PostgreSQL. Code blocks run on request and save their output below them. The file stays plain Markdown.

Live values · Runnable blocks · Boards

Agents

Claude Code, Codex, Gemini CLI, opencode or Greed's own agent run in a pane. Outside agents connect over MCP. Proposed edits show in the buffer for you to accept or reject. An agent can work in its own workspace, and you review its changes when it's done.

Agents

Plugins

Keys, modes, pickers, themes and the agent support are Luau plugins on the same typed API yours use. A plugin declares what it may access (files, programs, network) and is removed cleanly when unloaded.

Terminal or window

The window is drawn on the GPU, with ligatures, images and PDFs. Both show the same session.

Panes and floats

Splits, tabs, layouts and floating panes, with zellij's alt keys. They work inside terminals too.

A plugin

A folder with an init.luau. This one adds a command and binds it to space U. greed new NAME makes one with a test, and greed test NAME runs it.

Writing plugins · Luau API

local greed = require("@greed")

greed.command({
	name = "upper",
	doc = "Upper-case the selections",
	run = function(ctx)
		ctx.buffer:edit(function(e)
			for _, r in ctx.view:selection().ranges do
				local from, to = math.min(r.anchor, r.head), math.max(r.anchor, r.head)
				e:replace(from, to, string.upper(ctx.buffer:slice(from, to)))
			end
		end)
	end,
})

greed.keymap.bind({ layer = "leader" }, { U = "upper" })

Install

macOS app Linux x86_64 Linux arm64 

$ brew install johnae/greed/greed             # macOS or Linux
$ brew install --cask johnae/greed/greed-app  # Greed.app
$ nix run github:johnae/greed                 # Nix
$ tar -xzf greed-*-linux-x86_64.tar.gz -C ~/.local --strip-components=1

The releases page also has a static terminal-only build for any Linux. The first start asks for an editing style and a theme; :tutor teaches the keys.
