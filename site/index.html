Greed

A modal text editor. You pick the keys (Helix, Vim or VS Code), and it comes with a shell, terminals, notes and mail, with agents in all of them. It runs in a terminal or a window, locally or over ssh.

I wanted an editor I could bend as far as Emacs, without it ever freezing on me while a plugin thinks. So everything outside a small Rust core is a Luau plugin.

Install Docs

Notes and todos

greed notes opens Hoard: what's due, today's note, and a search over all your notes. Write a todo the way you'd say it (call the bank tomorrow 18:00) and it gets its date and reminder. Notes are just Markdown files in a folder, so an Obsidian vault works as it is. Ask your notes something and the agent answers with links to what it read.

Hoard

Mail

greed mail keeps a copy of your IMAP accounts in one list, searched as you type, offline too. HTML mail is laid out as text with nothing loaded from anywhere, so no tracking pixels. A message becomes a todo in your notes, and the agent can tell you what needs an answer this week.

Mail

Helix, Vim or VS Code keys

Pick a style on first start, and :style switches later. Each style keeps its own modes. Commands, pickers and plugins are the same for all of them.

Editing styles

Helix

% s todo enter c done

Select every todo, change them all.

Vim

:%s/todo/done/g

Substitute, with a preview as you type.

VS Code

ctrl-d ctrl-d done

Add the next match as a cursor.

Sessions and ssh

:detach leaves the session running, and greed attach brings you back, here or in a window. greed ssh HOST runs it on the other machine with your local config, which is really nice for a build box.

Editing on another machine

$ greed src/main.rs
$ greed --gui   # a window
:detach
$ greed attach
$ greed ssh build-box

Shell

:shell keeps each command's output as a block you can search, filter and run again. Tables from kubectl, docker or ps filter like so: where STATUS != Running, and chart too. For anything else, a terminal pane runs your own shell.

The shell

Live Markdown

Fields, formulas and computed columns, updated as you type, with charts under tables. Data blocks read CSV, SQLite or PostgreSQL, and code blocks run when you ask and keep their output below them. The file stays plain Markdown.

Live values · Runnable blocks · Boards

Agents

Claude Code, Codex, Gemini CLI and opencode run in a pane over ACP, and so does Greed's own agent, with whatever model you set up. MCP clients connect from outside. Edits they propose show up in the buffer for you to accept or reject.

Agents

  • Keys, modes, pickers, themes and the agents are all Luau plugins, on the same typed API yours get. A plugin says what it may touch (files, programs, the network) and you decide.
  • The window is drawn on the GPU, with ligatures, images and PDFs. Terminal and window show the same session.
  • Splits, tabs, layouts and floating panes on zellij's alt keys, inside terminals too.

A plugin

A folder with an init.luau - that's it. This one adds a command and puts it on space U. greed new NAME gets you one with a test, and greed test NAME runs it.

Writing plugins · Luau API

local greed = require("@greed")

greed.command({
	name = "upper",
	doc = "Upper-case the selections",
	run = function(ctx)
		ctx.buffer:edit(function(e)
			for _, r in ctx.view:selection().ranges do
				local from, to = math.min(r.anchor, r.head), math.max(r.anchor, r.head)
				e:replace(from, to, string.upper(ctx.buffer:slice(from, to)))
			end
		end)
	end,
})

greed.keymap.bind({ layer = "leader" }, { U = "upper" })

Install

macOS app Linux x86_64 Linux arm64 

$ brew install johnae/greed/greed             # macOS or Linux
$ brew install --cask johnae/greed/greed-app  # Greed.app
$ nix run github:johnae/greed                 # Nix
$ tar -xzf greed-*-linux-x86_64.tar.gz -C ~/.local --strip-components=1

The releases page also has a static terminal-only build for any Linux. The first start asks for an editing style and a theme, and :tutor walks you through the keys.

It's really early days, so expect some rough edges. That said, I use it daily - for code, notes and mail.
