Greed is good. General Runtime for Editing, Extending and Delegating.

Greed is a modal editor for the terminal and the window. The core is a small amount of Rust. Keys, modes, commands, pickers, themes and the agent integration are Luau plugins you can read, change or replace while it runs.

Get started Write a plugin 

$ greed src/main.rs          # edit; the session keeps running if you detach
:detach                      # leave it running in the background
$ greed attach               # come back to it
$ greed ssh build-box        # or edit on another machine, your config along
$ greed ctl focus            # ask the running editor what you're looking at
{ "path": "src/main.rs", "mode": "normal", "selections": [ ... ] }

Select, then act

Editing works like Helix: w selects a word, x a line, s every match of a regex, and typing then edits all of them at once. Prefer Vim, or no modes at all? :style vim and :style edit switch while it runs.

Plugins all the way down

Everything you see comes from plugins in Luau, written against the same typed API yours use. Each runs in a sandbox with a time budget, and unloading one takes away everything it added.

Sessions that keep running

The editor runs as a session with thin clients. Detach and come back to your open files, undo history and language servers, or use greed ssh to edit on another machine with your config brought along.

Agents as clients

Agents reach the editor over MCP, greed ctl and Claude Code's /ide. They see what you have open and propose edits you review in the buffer. They can write plugins too, which Greed type checks and tests before you approve them.

Terminal or window

The same session shows in your terminal or in a window drawn on the GPU, with ligatures, images, PDFs, prose in a proportional font and Markdown shown as a document. One theme styles both.

Notes and todos

Markdown notes with links, todos and an agenda, kept as plain files in a folder of your choosing, with tools agents can use to read and add to them.

A plugin is a folder

This one adds a command and binds it to g u. Put it in ~/.config/greed/plugins/upper/, or run greed new upper there to get one with a test. greed test upper runs its tests in a headless editor.

Writing plugins · The Luau API

local greed = require("@greed")

greed.command({
	name = "upper",
	doc = "Upper-case the selections",
	run = function(ctx)
		ctx.buffer:edit(function(e)
			for _, r in ctx.view:selection().ranges do
				local from, to = math.min(r.anchor, r.head), math.max(r.anchor, r.head)
				e:replace(from, to, string.upper(ctx.buffer:slice(from, to)))
			end
		end)
	end,
})

greed.keymap.bind("normal", { ["g u"] = "upper" })

Try it

Greed builds with a recent stable Rust and cmake:

$ git clone https://github.com/johnae/greed && cd greed
$ cargo build --release
$ ./target/release/greed README.md

To install it, cargo install --path crates/greed-editor, or with Nix, nix-build. The default plugins are built into the binary, so it runs from anywhere.

Greed is early and changes often.
